# CampusEats

CampusEats is a campus food delivery web service project.

The system allows students to browse campus restaurants and menus, manage their profile and delivery addresses, add items to a cart, place orders, make payments, and track deliveries.

## Project Structure

- `README.md` — Project overview
- `http-log.md` — HTTP request and response analysis
- `network-analysis.md` — Browser Network analysis
- `brief.md` — CampusEats system brief

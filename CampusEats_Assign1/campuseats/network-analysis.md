# Network Analysis

## Website Analyzed

IIIT Vadodara — https://www.iiitvadodara.ac.in

The browser's DevTools Network panel was used with "Disable cache" enabled. The page was then reloaded.

## Results

- **Total requests:** 113
- **Total transferred:** 29.3 MB
- **Slowest resource:** `10.png` — 24.9 seconds
- **3xx/4xx responses:** None observed. All observed requests returned `200`.

## Observation

The page made 113 network requests during the reload and transferred 29.3 MB of data. The slowest resource observed was `10.png`, which took 24.9 seconds to load. No 3xx or 4xx responses were observed.
